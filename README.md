# Modelado matemático

Preparación para el MCM/ICM, el HiMCM y los concursos de modelado: las familias de problemas continuos, discretos, de redes, de datos y de políticas, con el ciclo del modelado, el código, el informe, el trabajo de un equipo de tres en cuatro días y simulacros completos.

**Ver en línea:** https://aaramirez.github.io/modelado-matematico/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
